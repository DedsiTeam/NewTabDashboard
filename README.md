# 蓝色新标签页

React 19、TypeScript 与 Vite 构建的 Chrome 新标签页扩展。项目是纯前端实现，不调用业务 API。

## 开发

```bash
bun install
bun run dev
```

## 构建 Chrome 扩展

```bash
bun run build
```

构建完成后：

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `dist` 目录。

## 本地数据

扩展正式环境使用 `chrome.storage.local` 保存待办事项、全部分组、快捷入口和姓名，Vite 开发环境自动降级使用 `localStorage`。旧版 `localStorage` 数据会在首次加载时自动迁移。

点击页面右上角的数据按钮可以：

- 按需授权读取 Chrome 书签，并选择文件夹或书签追加到当前快捷入口。
- 导出包含全部数据的 JSON 备份。
- 从 JSON 备份恢复数据。

卸载扩展会清除 `chrome.storage.local`，建议定期导出备份。

交互说明：

- 顶部“搜索”或 `Ctrl + K`：全局搜索大分组、小分组、快捷入口、网址和待办。
- 顶部“编辑布局”：在使用模式与编辑模式间切换；增删改和拖动布局仅在编辑模式显示。
- 左侧待办栏顶部搜索框：按内容筛选待办。
- 待办栏固定显示在左侧；底部左箭头可折叠为窄栏，窄栏底部右箭头可重新展开，状态会自动保存。
- 待办栏右上角 `+`：通过弹窗填写必填的标题与多行内容，并选择标记颜色。
- 点击待办卡片：打开弹窗查看完整标题、内容和标记颜色。
- 拖动待办左侧手柄：调整待办的显示顺序。
- 待办右侧铅笔与删除按钮：修改或删除待办。
- 点击小分组名称：折叠或展开内容，状态会自动保存。
- 编辑模式下，小分组设置按钮：可选择快捷入口一行一个或一行两个。
- 编辑模式下，大分组右上角 `+`：添加小分组。
- 大分组右上角铅笔：修改大分组名称。
- 小分组右上角 `+`：添加快捷入口。
- 快捷入口右上角铅笔：修改名称和网址；始终优先使用网站 favicon，加载失败时回退到默认链接图标。
- 拖动快捷入口：可调整顺序，也可移动到任意大分组中的小分组。
- 拖动小分组标题左侧手柄：可排序，也可移动到其他大分组。
- 鼠标悬停或键盘聚焦快捷入口：显示完整网址。
- 右键快捷入口：删除该入口。
- 小分组右上角 `×`：删除小分组。
- 页面两侧箭头：横向切换大分组。
