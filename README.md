# 新标签页仪表板

React 19、TypeScript 与 Vite 构建的 Chrome 新标签页扩展。项目是纯前端实现，不调用业务 API。

## 开发

```bash
bun install
bun run dev
```

## 构建 Chrome 扩展

```bash
bun run build
```

构建完成后：

1. 打开 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `dist` 目录。

## 本地数据

扩展正式环境使用 `chrome.storage.local` 保存全部卡片、快捷入口和姓名，Vite 开发环境自动降级使用 `localStorage`。旧版 `localStorage` 数据会在首次加载时自动迁移。

点击页面右上角的数据按钮可以：

- 按需授权读取 Chrome 书签，并选择文件夹或书签追加到当前快捷入口。
- 导出包含全部数据的 JSON 备份。
- 从 JSON 备份恢复数据。

卸载扩展会清除 `chrome.storage.local`，建议定期导出备份。

交互说明：

- 顶部“搜索”或 `Ctrl + K`：搜索卡片、快捷入口和网址。
- 顶部“编辑布局”：切换编辑模式。可新建卡片、修改卡片名称、设置每行 2–5 个链接、拖动卡片定位，以及拖动链接项排序。列数增加时卡片宽度会增大。
- 卡片按固定网格坐标排列，宽度由链接列数决定，高度按实际内容占格；编辑模式下可把卡片拖入空位，位置会保存，遇到占用的格子时其他卡片顺延。页面内边距为 1rem，拖动时显示网格落点预览和位移动画。
- 在编辑模式下可以右键删除链接。
- 通过数据按钮可导入 Chrome 书签、导出或恢复备份。旧版大分组中的小分组会自动铺平为卡片，链接会保留。
